# Syneva

An integrated review environment (IRE) for code you didn't write by hand.

Fresh start. The previous implementation is archived at
[NextNodeSolutions/syneva-archive](https://github.com/NextNodeSolutions/syneva-archive).

The dashboard signs users in with Better Auth and reads selected GitHub App repositories and pull requests. See [GitHub setup](docs/github-setup.md) for App registration, vault configuration, and local development.
